# 지점 근로계약서 등록 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 지점이 근로계약서 발송 대상 인적사항을 직접 등록하고 발송 상태를 확인하며 파트타이머 양식을 내려받게 하고, 그 내역이 관리자 페이지에 뜨게 한다.

**Architecture:** 신규 시스템이 아니다. 지점 화면 `LaborContractTab`의 `isAdmin` 차단을 걷어내고, 급여를 화면에서 숨기고, 관리자가 바꾼 상태를 읽기 전용으로 표시한다. 저장은 이미 지점·관리자가 같은 Firestore 공유데이터 키를 쓰고 있어 연동은 저절로 된다. 파트타이머 양식만 신규 — Firestore 공유데이터에 base64로 보관한다.

**Tech Stack:** React 19 + TypeScript, Vite, Tailwind CSS 4, Firebase Firestore (`gasClient` → `firebaseDirect` 래퍼)

## Global Constraints

- **테스트 프레임워크가 이 저장소에 없다.** `package.json`의 스크립트는 `dev` / `build` / `start` / `clean` / `lint`뿐이며 테스트 러너·테스트 파일이 전무하다. 따라서 이 계획은 TDD 대신 저장소의 기존 검증 관례를 따른다: **`npm run lint`(= `tsc --noEmit`) → `npm run dev` 로컬 화면 확인 → Codex 리뷰.** 각 태스크의 검증 단계는 이 3단계로 구성한다. 테스트 러너를 새로 도입하지 않는다(이번 작업 범위 밖의 저장소 관례 변경).
- **커밋 금지.** 사용자가 "배포해"/"푸시해"라고 직접 지시하기 전까지 `git commit`·`git push`를 실행하지 않는다. 각 태스크 끝에 커밋 단계를 두지 않는다. 작업은 워킹트리에 쌓아두고, 사용자 지시가 있을 때 한 번에 커밋한다.
- **Codex 리뷰 필수.** 한 줄만 고쳐도 구현 직후 Codex 지독한 리뷰를 돌린다 (Task 7).
- **색상은 `DESIGN.md` 토큰만 사용.** 새 색을 만들지 않는다. 기존 파란색은 `#2E6DB4`(hover `#20528B`).
- **급여 상한 파싱 규칙 유지:** `parseSalaryInput`의 기존 동작(`250만`/`250`/`2500000` → 2,500,000)을 바꾸지 않는다.
- **양식 파일 원본 상한: 700KB** (`TEMPLATE_MAX_BYTES = 700 * 1024`). Firestore 문서 1MB 상한 - base64 33% 증가분 대비 여유.
- **공유데이터 키는 이중 저장 유지:** 계약 내역은 `labor_contracts_<지점>`과 `labor_contracts:<지점>` 두 키에 모두 쓴다. 관리자 조회(`firebaseGetAllLaborContracts`)가 `labor_contracts:` 접두사만 스캔하므로 `:` 키를 빠뜨리면 관리자 화면에서 사라진다.

**설계 근거 (왜 두 개로 나누는가):** 양식 파일은 최대 약 930KB(base64)다. 한 문서에 메타와 파일을 같이 두면 지점이 탭을 열 때마다 버튼 하나 그리자고 1MB를 내려받는다. 메타(수십 바이트)와 파일 본문을 별도 문서로 나눠, **탭 로드 시엔 메타만, 파일은 다운로드 버튼을 눌렀을 때만** 읽는다.

**왜 `shared_data` 컬렉션을 쓰는가:** 신규 컬렉션은 Firebase 콘솔의 보안규칙이 열려 있지 않으면 `permission-denied`가 난다(규칙 파일이 저장소에 없어 확인 불가). 사용자가 콘솔 작업 없는 방안을 선택했으므로, 권한이 이미 보장된 `shared_data`를 쓴다.

const TEMPLATE_META_KEY = "labor_contract_template_parttime_meta";
const TEMPLATE_FILE_KEY = "labor_contract_template_parttime_file";

export async function firebaseGetLaborContractTemplateMeta() {
  return await firebaseGetSharedData(TEMPLATE_META_KEY);
}

export async function firebaseGetLaborContractTemplateFile() {
  const value = await firebaseGetSharedData(TEMPLATE_FILE_KEY);
  return value ? (value as { dataBase64?: string }).dataBase64 ?? null : null;

export async function firebaseSaveLaborContractTemplate(meta: unknown, dataBase64: string) {
  // 파일을 먼저 쓴다. 파일 쓰기가 실패하면 메타를 남기지 않아

  return { success: true };
}

const parseSalaryInput = (rawVal: string): number => {
  const raw = rawVal.trim();

const base64ToBlob = (dataBase64: string, mimeType: string) => {

  return new Blob([bytes], { type: mimeType || "application/octet-stream" });
};

  // 저장 직전에 서버 최신본을 다시 읽고, 내가 건드린 레코드에만 변경분을 얹는다.
  const mutateContract = async (id: string, change: Partial<LaborContract>) => {
    setSaving(true);
    try {
      const latest = await readContracts();
      const next = latest.map((item) => (item.id === id ? { ...item, ...change } : item));
      if (!next.some((item) => item.id === id)) {
        window.alert("이미 관리자가 삭제한 내역입니다. 목록을 새로 불러옵니다.");
        await loadData();
        return false;
      }
      await writeContracts(next);
      return true;
    } catch (err) {
      console.error("근로계약서 저장 실패", err);
      window.alert("저장에 실패했습니다. 인터넷 연결과 로그인 상태를 확인한 뒤 다시 시도해 주세요.");
      return false;
    } finally {
      setSaving(false);
    }
  };

  const saveContract = async () => {
    if (!isLoaded) {
      window.alert("등록 내역을 아직 불러오지 못했습니다. 다시 시도한 뒤 등록해 주세요.");
      return;
    }
    const digits = onlyDigits(phoneDigits, 8);
    if (!name.trim() || digits.length !== 8 || !salary.trim()) {
      window.alert("이름, 연락처 8자리, 급여를 모두 입력해 주세요.");
      return;
    }
    const numericSalary = parseSalaryInput(salary);
    if (!numericSalary) {
      window.alert("급여를 올바르게 입력해 주세요.");
      return;
    }
    setSaving(true);
    try {
      const latest = await readContracts();
      const next: LaborContract[] = [
        {
          id: `contract-${Date.now()}`,
          name: name.trim(),
          phone: formatPhone(digits),
          salary: numericSalary,
          status: "발송 대기",
          createdAt: new Date().toISOString()
        },
        ...latest
      ];
      await writeContracts(next);
      setName("");
      setPhoneDigits("");
      setSalary("");
    } catch (err) {
      console.error("근로계약서 등록 실패", err);
      window.alert("등록에 실패했습니다. 인터넷 연결과 로그인 상태를 확인한 뒤 다시 시도해 주세요.");
    } finally {
      setSaving(false);
    }
  };

  const startEdit = (contract: LaborContract) => {
    setEditingId(contract.id);
    setEditName(contract.name || "");
    setEditPhoneDigits(phoneTail(contract.phone));
  };

  // 이름·연락처만 바꾼다. 급여는 손대지 않는다 — mutateContract가 서버 레코드에 병합하므로 기존 급여가 보존된다.
  const saveEdit = async (id: string) => {
    const digits = onlyDigits(editPhoneDigits, 8);
    if (!editName.trim() || digits.length !== 8) {
      window.alert("이름과 연락처 8자리를 확인해 주세요.");
      return;
    }
    const ok = await mutateContract(id, {
      name: editName.trim(),
      phone: formatPhone(digits),
      editRequestedAt: new Date().toISOString()
    });
    if (ok) setEditingId(null);
  };

  const requestDelete = async (id: string) => {
    if (!window.confirm("삭제요청을 관리자에게 전달할까요? 급여가 다른 경우에는 삭제요청 후 새로 등록해 주세요.")) return;
    await mutateContract(id, { deleteRequested: true, deleteRequestedAt: new Date().toISOString() });
  };

  const downloadTemplate = async () => {
    if (!templateMeta) return;
    setDownloading(true);
    try {
      const dataBase64 = await gasClient.getLaborContractTemplateFile();
      if (!dataBase64) {
        window.alert("양식 파일을 찾을 수 없습니다. 본사에 문의해 주세요.");
        return;
      }
      const blob = base64ToBlob(dataBase64, templateMeta.mimeType);
      const url = URL.createObjectURL(blob);
      const anchor = document.createElement("a");
      anchor.href = url;
      anchor.download = templateMeta.fileName || "파트타이머_근로계약서";
      document.body.appendChild(anchor);
      anchor.click();
      document.body.removeChild(anchor);
      URL.revokeObjectURL(url);
    } catch (err) {
      console.error("양식 다운로드 실패", err);
      window.alert("양식을 내려받지 못했습니다. 잠시 후 다시 시도해 주세요.");
    } finally {
      setDownloading(false);
    }
  };

  const busy = saving || !isLoaded;

  return (
    <div className="space-y-4 animate-fade-in" id="labor-contract-tab">
      {loadFailed && (
        <div className="bg-rose-50 border border-rose-200 text-rose-700 text-sm font-bold rounded-xl p-3 flex items-center justify-between gap-3">
          <span>등록 내역을 불러오지 못했습니다. 등록·수정이 잠겼습니다(기존 내역 덮어쓰기 방지).</span>
          <button onClick={() => void loadData()} className="shrink-0 rounded bg-rose-600 text-white px-3 py-1 text-xs font-black">다시 시도</button>
        </div>
      )}

      <div className="bg-white p-4 rounded-2xl border shadow-sm">
        <div className="flex flex-wrap items-start justify-between gap-3">
          <div>
            <h3 className="font-black text-gray-800 flex items-center gap-2">
              <Briefcase className="w-4 h-4 text-[#2E6DB4]" /> 근로계약서 발송 인적사항 등록
            </h3>
            <p className="text-xs text-gray-400 mt-1">급여가 잘못된 경우에는 기존 내역 삭제요청 후 새로 등록해 주세요.</p>
          </div>
          <button
            onClick={() => void downloadTemplate()}
            disabled={!templateMeta || downloading}
            title={templateMeta ? templateMeta.fileName : "본사에서 양식 등록 전입니다."}
            className="flex items-center gap-1.5 rounded-xl border border-gray-200 bg-gray-50 px-3 py-2 text-xs font-black text-gray-600 disabled:opacity-40 disabled:cursor-not-allowed"
          >
            <Download className="w-3.5 h-3.5" />
            {downloading ? "받는 중…" : "파트타이머 근로계약서 양식"}
          </button>
        </div>

        <div className="grid grid-cols-1 md:grid-cols-4 gap-2 mt-4 items-center">
          <input value={name} onChange={(e) => setName(e.target.value)} placeholder="이름" className="border border-gray-200 rounded-xl px-3 py-2 text-sm font-bold bg-gray-50" />
          <div className="flex items-center border border-gray-200 rounded-xl bg-gray-50 overflow-hidden">
            <span className="bg-gray-100 px-3 py-2 text-sm font-extrabold text-gray-400 border-r">010</span>

          </div>
          <input value={salary} onChange={(e) => setSalary(e.target.value)} placeholder="급여 예: 250만" className="border border-gray-200 rounded-xl px-3 py-2 text-sm font-bold bg-gray-50" />
          <button
            onClick={() => void saveContract()}
            disabled={busy}
            title={!isLoaded ? "등록 내역을 불러오는 중입니다." : undefined}
            className="bg-[#2E6DB4] hover:bg-[#20528B] text-white py-2 px-4 rounded-xl text-xs font-black disabled:opacity-40 disabled:cursor-not-allowed"

      <div className="bg-white rounded-2xl border overflow-hidden shadow-2xs">
        <div className="overflow-x-auto">
          <table className="w-full min-w-[640px] text-sm">
            <thead>
              <tr className="bg-gray-50 text-left border-b text-gray-500 font-extrabold text-xs">
                <th className="p-3 w-28">등록일</th>
                <th className="p-3 w-32">이름</th>

                <th className="p-3 w-28">발송 상태</th>
                <th className="p-3">안내</th>
                <th className="p-3 text-center w-40">요청</th>
              </tr>
            </thead>
            <tbody>
              {loading ? (
                <tr><td colSpan={6} className="p-6 text-center"><LoadingSpinner size="sm" /></td></tr>
              ) : contracts.length === 0 ? (
                <tr><td colSpan={6} className="p-6 text-center text-gray-400 font-bold">등록된 인적사항이 없습니다.</td></tr>

                  <td className="p-3 font-mono text-xs text-blue-700 font-black">
                    {editingId === c.id ? (
                      <div className="flex items-center">
                        <span className="text-gray-400 mr-1">010</span>
                        <input value={editPhoneDigits} onChange={(e) => setEditPhoneDigits(onlyDigits(e.target.value, 8))} className="w-24 border rounded-lg px-2 py-1" />
                      </div>
                    ) : c.phone}
                  </td>
                  <td className="p-3">
                    <span className={`rounded-full px-2 py-1 text-xs font-black ${statusChipClass(normalizeStatus(c.status))}`}>
                      {normalizeStatus(c.status)}
                    </span>
                  </td>
                  <td className="p-3 text-xs text-gray-500">
                    {c.deleteRequested
                      ? <span className="font-black text-rose-600">삭제요청됨</span>

                  </td>
                  <td className="p-3 text-center space-x-1.5">
                    {editingId === c.id ? (
                      <button onClick={() => void saveEdit(c.id)} disabled={busy} className="px-2.5 py-1 bg-[#2E6DB4] text-white rounded-lg text-xs font-black disabled:opacity-40">저장</button>
                    ) : (
                      <button onClick={() => startEdit(c)} disabled={busy} className="px-2.5 py-1 bg-slate-100 text-slate-700 rounded-lg text-xs font-black disabled:opacity-40">수정</button>
                    )}
                    <button onClick={() => void requestDelete(c.id)} disabled={busy} className="px-2.5 py-1 bg-rose-50 text-rose-700 rounded-lg text-xs font-black disabled:opacity-40">삭제요청</button>
                  </td>
                </tr>
              ))}
            </tbody>
          </table>
        </div>
      </div>
    </div>
  );
}

- [ ] **Step 4: 업로드 핸들러 추가**

`saveBranchContracts`(3108행) 정의 바로 위에 추가:

```tsx
  // Firestore 문서 1개는 약 1MB가 상한이고 base64는 원본보다 약 33% 커진다.
  // 700KB를 넘으면 저장이 실패하므로 업로드 시점에 막는다.
  const TEMPLATE_MAX_BYTES = 700 * 1024;

  const handleTemplateUpload = async (event: React.ChangeEvent<HTMLInputElement>) => {
    const file = event.target.files?.[0];
    event.target.value = ""; // 같은 파일을 다시 골라도 onChange가 뜨도록 초기화
    if (!file) return;
    if (file.size > TEMPLATE_MAX_BYTES) {
      window.alert(`파일이 너무 큽니다. 최대 700KB까지 등록할 수 있습니다.\n선택한 파일: ${Math.round(file.size / 1024)}KB`);
      return;
    }
    setUploadingTemplate(true);
    try {
      const dataBase64 = await new Promise<string>((resolve, reject) => {
        const reader = new FileReader();
        reader.onload = () => {
          const result = String(reader.result || "");
          const comma = result.indexOf(",");
          resolve(comma >= 0 ? result.slice(comma + 1) : result);
        };
        reader.onerror = () => reject(reader.error);
        reader.readAsDataURL(file);
      });
      const meta: LaborContractTemplateMeta = {
        fileName: file.name,
        mimeType: file.type || "application/octet-stream",
        size: file.size,
        uploadedAt: new Date().toISOString()
      };
      await gasClient.saveLaborContractTemplate(meta, dataBase64);
      setTemplateMeta(meta);
      window.alert("파트타이머 근로계약서 양식을 등록했습니다.");
    } catch (err) {
      console.error("양식 등록 실패", err);
      window.alert("양식 등록에 실패했습니다. 잠시 후 다시 시도해 주세요.");
    } finally {
      setUploadingTemplate(false);
    }
  };
```
