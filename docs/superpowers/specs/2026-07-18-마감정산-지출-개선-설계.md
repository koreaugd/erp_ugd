## 근본 원인 · 설계

### #5 쿠팡/네이버 (현금)
`ExpenseGrid`는 현금·카드 공용. `usageOptions = variant==="cash" ? CASH_USAGES : EXPENSE_USAGES`로 분기. `CASH_USAGES`(expenseRows.ts 신설) = `EXPENSE_USAGES`에서 쿠팡·네이버 제외. 빈 행 기본 사용처가 "쿠팡"이라 현금에서 무효 → `createEmptyExpenseRow` 기본값을 **중립값 "그외기타"**로 변경(카드도 동일; 옵션은 그대로라 카드는 필요 시 쿠팡/네이버 선택). 월말 현금 수정 드롭다운도 `CASH_USAGES` 사용, 카드는 `EXPENSE_USAGES`.

### #8 한글→영문 (근본 원인 확인됨)
**원인**: 금액칸의 `inputMode="numeric"`이 **윈도우 크롬에서 IME를 영문으로 전환하고 그 상태가 전역으로 남는다**(윈도우 IME는 칸별이 아니라 전역). 그래서 금액칸을 거친 뒤 상세칸이 영문이 된다. `lang="ko"`(상세칸)로는 안 됨 — 문제는 상세칸이 아니라 금액칸이 IME를 오염시킨 것.
**수정**: **PC 시트 금액칸에서 `inputMode="numeric"` 제거**. 데스크톱은 물리 키보드라 숫자키가 IME와 무관하게 입력되고, 숫자 필터는 `handleAmountInput`이 그대로 담당. 모바일 카드뷰 금액칸은 숫자 키패드가 필요해 유지. (사용자 검증 완료: 마우스·키보드 이동은 무관, 금액칸 경유 시에만 영문 → inputMode 제거 후 한글 유지 확인)

### #6 수정 드롭다운 + 저장 속도
- **드롭다운**: `AdminRecordEditModal`이 이미 `options` 지원. 거래처/사용처·분류항목 필드에 목록 전달. 현재 값이 목록에 없으면(레거시) `withCurrent`로 그 값을 앞에 끼워 빈 칸 방지.
- **저장 속도**: 기존은 `getDailyDetail + updateDaily + refreshHistory(전체 재조회)`를 순서대로 await → 느림. → **낙관적 갱신**: 저장 성공 즉시 `items`의 그 행만 patch하고 모달 닫음, `refreshHistory`는 백그라운드(await 안 함). 저장 성공(await updateDailyMetadata)은 서버 반영을 보장하므로 백그라운드 재조회가 서버 값으로 재정렬. 실패 시 alert 후 중단(patch 안 함).

### #7 지점 수정 버튼 + 이력 무결성
- 수정/삭제 버튼이 `isAdmin` 게이트라 지점엔 없음 → **관리 컬럼 항상 표시**, **수정 버튼은 지점·관리자 모두**, **삭제는 관리자만**. (카드 표는 관리 헤더가 누락돼 있던 것도 보완, colSpan 정정)
- **감사 무결성**: `updateDailyMetadata(recordId, updater, actor)`의 actor 기본값이 "관리자". 지점 편집 시 반드시 `actor = isAdmin ? "관리자" : branchName` 전달 — 안 그러면 지점 수정이 이력에 "관리자가 고침"으로 거짓 기록.

## Codex 리뷰 반영 (배포 전 강화)
지독한 리뷰 → 확인 리뷰 2라운드로 아래를 잡아 수정:
- **P0 (동시 삭제 시 인덱스 밀림 → 엉뚱한 행 덮어씀)**: 저장 전 `metadata.*Expenses[item.metaIndex]`의 **금액·상세·사용처·분류**를 로드 당시 값(item 빌드와 같은 fallback: `||"공란"`/`||"미분류"`/`||""`)과 대조. 다르면 `STALE_METAINDEX` throw → "목록 바뀜" 안내 + 새로고침. 네 값이 다 같으면 동일 행이라 안전.
- **P1 (silent 재조회 실패 시 화면 비워짐)**: `getBranchHistory`는 실패를 `[]`로 삼켜 `setHistory([])`가 화면을 통째로 지웠음. silent 경로를 **fail-closed `getBranchHistoryFromServer`(실패 시 throw)**로 교체 → 실패 시 catch로 흘려 history 유지(수정·기존 데이터 보존). non-silent·타 호출부는 기존 API 유지.
- **P2 (옛 쿠팡/네이버 값 미표시)**: `usageOptionsFor(current)`로 저장값이 목록에 없으면 앞에 끼워 표시.
최종 확인 리뷰: "회귀 없음/수정 적절", 종료 게이트 ALLOW.
