# 근로계약서 입력 확장 + 관리자 화면 정리 설계서 (그룹 A)

> 작성일: 2026-07-18
> 대상: `src/pages/branch/tabs/LaborContractTab.tsx`, `src/pages/AdminPage.tsx`, `src/api/gasClient.ts`
> 선행: [[2026-07-17-지점-근로계약서-등록-설계]] (최초 기능, 984d6f6 배포됨)

## 1. 목적

이미 배포된 근로계약서 발송 등록 기능에, **신규입사/지점이동 구분과 날짜·이전지점 입력**을 더하고, 지점 폼과 관리자 화면의 **디자인·정보 구조를 정리**한다.

## 2. 요구사항 (확정)

1. 지점탭: 파트타이머 양식 버튼을 **맨 왼쪽 허니듀 색 세로 버튼**으로("파트타이머 / 근로계약서 양식" 2줄), 등록 폼은 폭 축소·V2 톤(주류재고·발주관리) 컴팩트.
2. 지점탭 입력 확장 — 순서: **구분(신규입사/지점이동, 드롭다운 기본"선택") → 날짜(입사일/지점이동일) → 이름 → 연락처 → 급여 → (지점이동 시)이전지점 → 등록**을 한 줄로.
3. 지점이동도 **급여 필수**. 이전지점은 지점이동일 때만 필수(전 지점 목록에서 현재 지점 제외).
4. 급여 입력 시 **3자리 쉼표 자동**("250만" 표기도 계속 허용).
5. 목록 표: 모든 컬럼 **한 줄 고정**, 단 지점이동의 **이전지점명만 7자 초과 시 줄바꿈**. 구분 칩 색 = 신규입사 **바닐라**, 지점이동 **허니듀**.
6. 관리자: "**지점 등록 후보**"(직원현황 자동감지) 탭 **완전 제거** → 지점이 요청한 **발송 내역만** 표시. 표에 **구분/입사·이동일/이전지점** 컬럼 추가.
7. 관리자: 지점명 필터를 **드롭다운(기본"지점 선택"=전체)**, 옵션은 발송 내역에 실제 있는 지점만.
8. 관리자 사이드바: **근로계약서 발송 현황 ↔ 연차관리 순서 교체**(근로계약서가 위).

## 3. 저장 구조

`LaborContract`(gasClient.ts)에 선택 필드 3개 추가 — 옛 레코드엔 없어 표시 시 "-":

```
contractType?: "신규입사" | "지점이동";
effectiveDate?: string;   // 입사일 또는 지점이동일 (YYYY-MM-DD)
previousBranch?: string;  // 지점이동일 때만
```

저장 키(`labor_contracts:`/`_`)·lost-update 방지 재조회 병합·수정 시 이름·연락처만 병합은 기존과 동일. 구분/날짜/이전지점/급여는 삭제요청 후 재등록으로 변경(기존 급여 규칙과 동일).

## 4. 구현 요점

### 4.1 지점탭 (LaborContractTab)
- 허니듀 양식 버튼: `bg-emerald-*` 클래스를 버튼에 쓰면 `.branch-redesign button[class*="bg-emerald-"]` 규칙이 검정으로 강제하므로, **인라인 `style backgroundColor: var(--branch-honey)`**로 칠한다.
- 구분 드롭다운 기본값 "" ("선택"). 등록 시 미선택이면 안내. 지점이동 아니면 previousBranch 초기화.
- 급여 `formatSalaryTyping`: 순수 숫자면 `toLocaleString`, 그 외("250만")는 그대로. `parseSalaryInput`이 쉼표/만 처리.
- 이전지점 옵션: loadData에서 `getBranchList` → role=branch, 현재 지점 제외.
- 표: 모든 td `whitespace-nowrap`. 이전지점명만 `max-w-[5rem] break-all`(약 7자 후 줄바꿈). 칩 색은 브랜치 화면 remap 활용(신규입사 `bg-amber-50`→vanilla, 지점이동 `bg-emerald-50`→honey).

### 4.2 관리자 (AdminPage)
- **후보 기능 완전 제거**: `activeTab`/`candidateRows`/`candidateFilter` 상태, loadData의 roster 스캔, `filteredCandidates`/`candidateCounts` 메모, 탭 바, 후보 테이블, 그리고 후보 전용 타입·헬퍼(`ContractCandidate*`, `isContractCandidateEmployee`, `getContractCandidate*`, `formatContractCandidatePhone`, `getAdminReasonChipClass`, `AdminLaborContractSubTab`)와 안 쓰게 된 `RosterEmployee` import 삭제. `getBranchOwnRoster`(gasClient)는 다른 기능에서 쓰여 유지.
- 발송 내역 표에 구분/입사·이동일/이전지점 컬럼 추가.
- 지점명 필터: `branchOptions`(contracts에서 유니크·가나다순) 드롭다운, 필터는 정확 일치(`===`).
- 사이드바: laborContracts 버튼을 annualLeave 앞으로.
